USB MEMORY KIT
==============

This USB stick is a portable log archive and local memory interface.

1. Double-click 控制台.cmd for the terminal-style field console.
2. Choose [1] to sync this computer's logs, vectorize them and rebuild communities.
3. Or double-click 吸收日志.cmd to run that full pipeline directly.
4. Double-click 启动检索.cmd to open the local memory interface in portable Firefox.
   (always use this address, never double-click memory-kit\web\index.html)

Views:
- 智能检索: semantic and keyword search
- 原始日志: copy and read the original files
- 光场: data-driven HALOFLUX visualization

Private logs, indexes, models, runtime files and user files are not part of the
public layout. See README.md, USB-LAYOUT.md and CREDITS.md for details.

Raw copies: memory-kit\corpus\<COMPUTERNAME>\
Chunks:     memory-kit\index\chunks.jsonl
Vectors:    memory-kit\index\vectors.jsonl
